## Guide

## Visualization  
For visualization, it is best to work with Jupyter Notebook. Visual Studio Code may not always render the required graphs properly.
We have created GraphPlots for visualization separately. The config has checks in place to turn on and off separately.

## Authentication  
Config File has masked key values, thus it would need to be issued from creating accounts at the required api access links by creating new account. The If you need password/authentication access, please contact us.
